# Super Apps MATSANDATAMA - Product Context

## Product Identity

**Name**: Super Apps MATSANDATAMA
**Full Name**: Super Apps Madrasah Tsanawiyah Negeri 2 Kota Malang
**Institution**: MTsN 2 Kota Malang (Madrasah Tsanawiyah Negeri 2 Kota Malang)
**Type**: Enterprise Education Management System
**Platform**: Web (Progressive Web App)
**Version**: 1.2.1

## Purpose

Sistem digital terintegrasi untuk pengelolaan akademik, jurnal mengajar, administrasi siswa, dan layanan madrasah yang menggabungkan teknologi modern dengan nilai-nilai Islamic education.

## Target Audience

### Primary Users
1. **Guru** (Teachers)
   - Age: 25-55 tahun
   - Tech Savvy: Medium
   - Primary Tasks: Input jurnal mengajar, input nilai, lihat jadwal
   - Pain Points: Butuh sistem cepat untuk jurnal harian, sering mobile

2. **Siswa** (Students)
   - Age: 12-15 tahun (SMP/MTs)
   - Tech Savvy: High (digital natives)
   - Primary Tasks: Lihat jadwal, tugas, materi, nilai
   - Pain Points: Butuh UI yang engaging, akses mudah dari HP

3. **Admin/Tata Usaha**
   - Age: 30-50 tahun
   - Tech Savvy: Medium-High
   - Primary Tasks: Kelola data siswa, GTK, jadwal, laporan
   - Pain Points: Data sangat banyak, butuh sistem yang organized

4. **Orang Tua/Wali**
   - Age: 35-55 tahun
   - Tech Savvy: Low-Medium
   - Primary Tasks: Monitoring anak (nilai, kehadiran, prestasi)
   - Pain Points: Tidak tech-savvy, butuh UI simpel & jelas

5. **Kepala Sekolah & Wakil**
   - Age: 40-60 tahun
   - Tech Savvy: Medium
   - Primary Tasks: Monitoring dashboard, laporan, approval
   - Pain Points: Butuh insight cepat, data-driven decision making

## Brand Identity

### Visual Identity
- **Primary Color**: Islamic Green #006837 (Traditional Islamic education)
- **Secondary Color**: Gold #C8A24A (Excellence & achievement)
- **Background**: Cream #FBF7EE (Warm, paper-like, welcoming)
- **Accent**: Ivory #FFFDF7 (Clean reading surface)

### Design Philosophy
1. **Islamic Aesthetic**: Subtle geometric patterns, warm earth tones, calming green
2. **Modern & Professional**: Clean layouts, crisp typography, purposeful animations
3. **Accessible**: WCAG AA compliant, keyboard navigation, screen reader friendly
4. **Localized**: Bahasa Indonesia, Indonesian naming conventions, Islamic calendar support

### Typography
- **Primary**: Plus Jakarta Sans (Modern, friendly, Indonesian-designed typeface)
- **Monospace**: IBM Plex Mono (Data, codes, technical information)

### Patterns & Motifs
- Subtle Islamic geometric patterns (non-intrusive, background elements)
- Mosque dome silhouettes for empty states
- Arabesque-inspired borders for emphasis
- Radial gradients mimicking Islamic tile work

## User Journeys

### Critical Path: Guru - Input Jurnal Mengajar
1. Login → Dashboard
2. Click "Jurnal Presisi"
3. Scan QR kode kelas
4. Auto-fill: Kelas, Mapel, Waktu
5. Input: Materi, Kendala
6. Submit → Success feedback
**Target**: < 60 detik

## Quality Standards

### Must-Have
- ✅ WCAG 2.1 Level AA accessibility
- ✅ Mobile-responsive (50%+ mobile traffic)
- ✅ Loading states for all async operations
- ✅ PWA installable

### Should-Have
- 🎯 Keyboard shortcuts (Cmd+K)
- 🎯 Dark mode support
- 🎯 Empty state illustrations
- 🎯 Micro-interactions

## Constraints

### Cultural
- Language: Bahasa Indonesia
- Calendar: Gregorian + Hijriyah
- Islamic design principles
