🎓 Seed Attendance Data

Buat data kehadiran untuk semua jurnal yang sudah ada

📋 Cara Menggunakan:

  1. Pastikan Anda sudah login sebagai Admin di aplikasi
  2. Klik tombol "Mulai Seeding" di bawah
  3. Tunggu proses selesai (biasanya beberapa detik)
  4. Setelah selesai, refresh halaman jurnal Anda
  5. Klik tombol "Detail" pada jurnal untuk melihat nama siswa
⚠️ Catatan Penting: Script ini akan membuat data kehadiran siswa untuk semua jurnal yang belum memiliki data kehadiran. Jurnal yang sudah memiliki data kehadiran akan dilewati.
